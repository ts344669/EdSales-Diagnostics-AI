# EdSales Diagnostics AI — версия для сдачи

Один интерфейс: CRM (учебные данные), AI-оценка звонка по 11 компетенциям, AI-предложения для ИПР, история и отчёт руководителя.

## Запуск Windows
1. `python -m pip install -r requirements.txt` (один раз).
2. В папке проекта создайте `.env` на основе `.env.example`, внесите личный `OPENAI_API_KEY`. Не отправляйте `.env` в чат и GitHub.
3. Запустите `start-windows.bat`; откройте `http://127.0.0.1:8000`.
4. Для теста выберите менеджера и этап «До обучения», дату, тип звонка, вставьте обезличенный текст, нажмите «Оценить звонок с ИИ» и «Сформировать ИПР с ИИ».
5. Для включения AI-предложений в основной ИПР используйте **имя одного из пяти менеджеров** и исходную оценку звонка (этап «До обучения»). Нажмите «Передать рекомендации в основной ИПР». Это предложения, а не автоматически утверждённые мероприятия.

## Что исправлено
- Для первичной консультации K08 «Допродажа» не оценивается: score=null, без штрафа и назначения упражнения.
- AI-план исключает критерии с null и баллами 4–5.
- Предложения AI можно передать в основной ИПР менеджера и видеть рядом с мероприятиями и проверками; руководитель сохраняет контроль над статусом.
- Исправлена устаревшая надпись про ручной JSON, введена проверка этапа **до** платного AI-вызова.
- Добавлен файл безопасного запуска Windows и простое ограничение количества запросов: до 8 запросов в час от одного IP и 50 за сутки на процесс. Это стартовые, не гарантированные лимиты — для реальной эксплуатации требуется серверная авторизация и устойчивое хранилище счётчиков.

## Публикация
1. В GitHub загрузите только `index.html`, `server.py`, `requirements.txt`, `.env.example`, `.gitignore`, `README.md`, `render.yaml`, `start-windows.bat`. **НЕ загружайте `.env`!**
2. На Render создайте веб-сервис из репозитория; среда Python, сборка `pip install -r requirements.txt`, запуск `uvicorn server:app --host 0.0.0.0 --port $PORT`. `render.yaml` содержит пример настроек.
3. В Render → Environment добавьте `OPENAI_API_KEY` (секретный ключ), `OPENAI_MODEL=gpt-4.1-mini`.
4. Проверьте публичный `/api/health`, затем **один** учебный запрос оценки и создание ИПР.
5. Ограничение расходов $2 в настройках OpenAI следует оставить. Посетители могут расходовать общий баланс, поэтому после сдачи ключ рекомендуется отключить либо ограничить доступ.

### Ограничения
- Все данные вымышленные; живые звонки с персональными данными загружать нельзя без отдельного правового и организационного решения.
- История и утверждения ИПР хранятся в браузере (localStorage); не синхронизируются между устройствами.
- AI-заключения требуют проверки методологом / руководителем.
- Приложение не включает отдельный EdSales Trainer: тренажёр — другой продукт.
- Обновление файлов не меняет адрес браузера, но учебная история должна храниться в том же браузере и на том же домене/порту.
